# Todo App

A responsive Todo application built with HTML, Tailwind CSS, and JavaScript. It helps you organize tasks, keep track of completed work, and monitor your overall progress through a simple interface.

**Live Demo:** [Open Todo App](https://sahil-verma77.github.io/Todo-App/)

## Features

- **Add Tasks:** Create tasks by entering a description.
- **Edit Tasks:** Update the description of an existing task.
- **Complete Tasks:** Mark tasks as completed or mark them incomplete again.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Statistics:** View the total number of tasks and the number completed.
- **Progress Tracking:** See your completion percentage with a progress bar that updates automatically.
- **Local Storage:** Tasks remain saved in your browser after refreshing the page.
- **Empty State:** Displays a helpful message when there are no tasks in the list.
- **Responsive Interface:** Layout adapts to different screen sizes.

## Tech Stack

- **HTML5** — page structure
- **Tailwind CSS** — styling and responsive layout
- **JavaScript** — task management and interactive functionality
- **Local Storage** — saving tasks in the browser

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sahil-verma77/Todo-App.git
   ```

2. Open the project folder:

   ```bash
   cd Todo-App
   ```

3. Open `index.html` in your web browser.
